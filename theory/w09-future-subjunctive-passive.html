🔮 虚拟式未来时 + 被动语态

futuro do subjuntivo（葡语独有，西语已废弃） · Se chover, fico em casa · Vendem-se casas · Precisa-se de vendedores

← 仪表盘
西语者须知：本周是葡语「独家内容」最多的一周。虚拟式未来时在西语里已经废弃（古西语的 si lloviere），但它在葡语是日常高频活语法：Se chover, fico em casa. / Quando você chegar, me avise. 好消息：规则动词的虚拟将来时 = 不定式原形（falar / comer / partir），不规则动词直接从 W5 背过的 perfeito 词干推导（foram → for）。被动语态则是你的舒适区：Vendem-se casas. = Se venden casas.——结构一模一样，唯一陷阱是代词位置（葡语正式文体 se 后置）。

1. futuro do subjuntivo 是什么

表示将来可能发生的假设：「如果明天下雨」「等你到了以后」。它永远挂在 se（如果）/ quando（当……时）/ assim que（一……就）/ caso（万一）/ quem（谁要是） 这类词后面，指向未来。西语里这个功能由现在时虚拟式代劳（si llueve / cuando llegues），葡语则保留了专门的时态——这是两语时态体系最大的分岔口。

2. 构成：规则动词 = 不定式原形（白送）

规则：拿 W5 perfeito 的 eles 形式，砍掉词尾 -ram → 即得词干
eles falaram → falar　　eles comeram → comer　　eles partiram → partir
规则动词的 eu/ele 形式 = 不定式原形！只有 tu（-es） 和 nós（-mos）、eles（-em） 需要变化。

tufalarescomerespartires原形 + es（巴西少用 tu）

3. 用法：五大触发场景

触发词葡语例句西语对照（重点差异！）
se 如果（真实可能）Se chover amanhã, fico em casa.Si llueve mañana… — 西语用现在时陈述式！
quando 当……时（未来）Quando você chegar, me avise.Cuando llegues, avísame. — 西语用现在时虚拟式！
assim que / logo que 一……就Assim que eu souber, te conto.En cuanto lo sepa, te lo cuento.
caso 万一 / 如果Caso chova, o jogo será cancelado.En caso de que llueva…（西语 caso 后接现在虚拟）
quem / onde / conforme 泛指Quem tiver dúvidas, fale comigo.Quien tenga dudas…（西语现在虚拟）
Se eu tiver tempo, viajo com você. / Quando eles chegarem, começamos a reunião. / Caso precise, ligue para mim. / Enquanto houver esperança, vamos lutar.
如果我有时间，就和你一起旅行。/ 等他们到了，我们就开会。/ 万一需要，给我打电话。/ 只要还有希望，我们就继续奋斗。
最高频错误（西语迁移病）：
① *Se choverá amanhã… ❌ —— se 后面禁用陈述式将来时，必须用虚拟将来时：Se chover…（西语 si lloverá 同样错，两语一致的禁区）；
② *Quando você chega, me avise. ❌（正式文体）—— 西语 cuando llegas 的思路直搬会出错：未来时间从句葡语用虚拟将来时 quando você chegar。巴西口语里确实能听到 chega，但考试和正式写作一律判错；
③ 记住语义分工：se + 虚拟将来时 = 很可能发生；se + 虚拟过去未完成 + 条件式（W8）= 不可能/低概率：Se chover, fico.（八成会下） vs Se chovesse, ficaria.（反正不会下）。

4. 被动语态一：ser + 过去分词

与西语 ser + participio 完全平行：时态由 ser 承担，分词与主语性数一致。

时态葡语西语对照
现在A lei é respeitada por todos.La ley es respetada por todos.
过去（perfeito）O projeto foi aprovado ontem.El proyecto fue aprobado ayer.
过去（imperfeito）As cartas eram entregues de manhã.Las cartas eran entregadas por la mañana.
将来Os casos serão julgados em março.Los casos serán juzgados en marzo.
完成A obra tem sido elogiada.La obra ha sido elogiada.（葡语 tem sido 表持续至今）
ser vs estar + 分词（两语逻辑一致）：A porta foi fechada pelo zelador.（动作：门被管理员关了）vs A porta está fechada.（状态：门关着）= fue cerrada / está cerrada。西语语感直接迁移。

5. 被动语态二：se + 动词（passiva sintética）★ 葡语正式文体主力

5.1 及物动词：se 被动句

Vendem-se casas. / Aluga-se apartamento. / Assinam-se os documentos na sexta-feira. / Precisa-se de engenheiros?
出售房屋。/ 出租公寓。/ 文件于周五签署。
一致规则：动词与后面的名词主语一致——Vende-se a casa（单）/ Vendem-se casas（复）。（最后一例见 5.2：de engenheiros 有介词，属不定主语句，动词用单数。）

5.2 不及物动词：se 不定主语句（índice de indeterminação do sujeito）

Vive-se bem no Brasil. / Trabalha-se muito aqui. / Precisa-se de vendedores. / Estuda-se melhor de manhã.
在巴西生活得很好。/ 这里工作很辛苦。/ 招聘销售员。/ 早上学习效率更高。
动词一律单数，主语是「不特定的人」——相当于 on vit bien / se vive bien。
代词位置：葡西最大的形式差异！
西语永远前置：Se venden casas.　葡语正式文体后置且句首不用 se：Vendem-se casas.
巴西口语里 Se vendem casas（前置，照西语习惯）到处可见，日常交流没问题；但新闻、公文、考试中规范形式是后置：Alugam-se apartamentos。
将来时/条件式的规范写法是中插（mesóclise）：vender-se-ão casas——巴西人自己也嫌拗口，实际写作改用 as casas serão vendidas，认识即可。

6. 三种「被动/不定」结构选择速查

场景结构例句
有明确施动者（by…）ser + 分词 + porA lei foi aprovada pelo Congresso.
无施动者、宾语变主语se + 动词（与名词一致）Vendem-se casas novas.
不特定的人做某事se + 动词（永远单数）Come-se bem aqui.
