第 6 周 · Phase 2

⏳ 进行时与完成时：estar + gerúndio · pretérito composto

gerúndio -ando/-endo/-indo · estar + gerúndio 可平移 · tenho falado ≠ he hablado

← 仪表盘
西语者须知：本周一半是坦途、一半是深坑。坦途：estar + gerúndio（进行时）与西语 estar + gerundio 结构完全一致，可以放心平移——Eu estou comendo = Estoy comiendo。深坑：pretérito perfeito composto（tenho falado）虽然和西语 he hablado 形式对应，语义却完全不同——这是本周头号陷阱，第 4 节务必精读。

1. Gerúndio 的构成：-ando / -endo / -indo

规则极其工整，与西语 -ando / -iendo 一一对应：

变位组词尾例词（葡）西语对照
-ar 动词-andofalar → falando / trabalhar → trabalhandohablando / trabajando
-er 动词-endocomer → comendo / fazer* → fazendocomiendo / haciendo
-ir 动词-indopartir → partindo / dormir → dormindopartiendo / durmiendo

注意：葡语 -er 动词用 -endo（不是西语 -iendo）：comendo ≠ comiendo。gerúndio 永远不带重音符号。

1.1 五个不规则 gerúndio（高频动词，必须硬记）

不定式葡语 gerúndio西语 gerundio备注
dizer（说）dizendodiciendo词干缩成 diz-
fazer（做）fazendohaciendo词干缩成 faz-
vir（来）vindoviniendo葡语反而更规则
pôr（放）pondoponiendopondo 中 n 鼻化前接 õ
trazer（带来）trazendotrayendo词干缩成 traz-
拼写陷阱：西语者极易把 haciendo / diciendo 直接写成葡语。葡语是 fazendo / dizendo——-endo 词尾、词干缩短。测验里西语形式会作为干扰项出现。

2. Estar + gerúndio：进行时（可直接平移！）

结构与西语 100% 平行：estar 变位 + gerúndio。

Eu estou comendo. / Você está estudando. / Nós estamos trabalhando. / Eles estão chegando.
我在吃饭。/ 你在学习。/ 我们在工作。/ 他们快到了。（= Estoy comiendo / Estás estudiando / Estamos trabajando / Están llegando）

estar 现在时变位：estou / está / está / estamos / estão（巴西用 você → está）。

分工例句含义
简单现在时Eu estudo português.我学葡语（习惯、常态、长期安排）
进行时Eu estou estudando português.我此刻正在学葡语 / 我最近在学（阶段性动作）
PT-BR vs PT-PT（了解即可）：巴西说 estou comendo；葡萄牙本土说 estou a comer（estar a + 不定式）。听到葡萄牙人说话别惊讶，本课程以巴西葡语为准。

3. 过去进行时与将来进行时

过去进行时 = estar 的 imperfeito + gerúndio，对齐 estaba + gerundio：

Eu estava estudando quando você ligou.
你打电话来的时候我正在学习。（= Estaba estudiando cuando llamaste）

estar 过去未完成变位：estava / estava / estava / estávamos / estavam。

将来进行时（口语高频）= ir + estar + gerúndio，或正式 futuro estará + gerúndio：

Amanhã a esta hora, eu vou estar viajando. / Não ligue às oito — nós vamos estar jantando.
明天这个时候我会在旅行。/ 八点别打电话——我们那会儿正在吃晚饭。（西语同样结构：voy a estar viajando）

4. ⚠️ Pretérito perfeito composto：tenho falado ≠ he hablado

构成：ter 现在时 + particípio：tenho / tem / tem / temos / têm + falado。形式上与西语 he / has / ha / hemos / han + hablado 工整对应——但语义南辕北辙：

西语 pretérito perfecto葡语 pretérito composto
核心语义He comido.（我吃过饭了——刚发生、与现在相关的单次动作）Tenho comido.（我最近一直在吃 / 反复吃——持续到现在）
典型状语hoy, esta mañana, ya, todavía noultimamente, nos últimos anos, sempre, todos os dias
例句Hoy he estudiado dos horas.（今天我学了两小时）Tenho estudado muito ultimamente.（我最近一直在猛学）
本周头号陷阱：在巴西葡语里，Tenho comido 不是"我吃过饭了"！它表示"我这段时间一直有在吃（某物）"。巴西人表达"刚做完/已经做了"用：
① Eu acabei de comer.（我刚吃完 = Acabo de comer）
② Eu comi.（我吃过了，简单过去时 ≈ He comido / Comí）
把西语 he comido 机械平移成 tenho comido，巴西人会觉得你在说"我最近一直在吃这个"。
Tenho estudado muito ultimamente. / Ela tem trabalhado até tarde. / Os preços têm aumentado nos últimos meses.
我最近一直在用功。/ 她最近总是工作到很晚。/ 近几个月物价一直在涨。（全部是"反复/持续到现在"）

5. Particípio：-ado / -ido 与高频不规则

规则：-ar → -ado（falado），-er / -ir → -ido（comido, partido）——与西语 -ado/-ido 完全平行。

不定式葡语 particípio西语 participio备注
fazerfeitohecho最高频不规则
dizerditodicho对应工整
vervistovisto同形
escreverescritoescrito同形

pôrpostopuestoue → o
morrermortomuertoue → o

gastargastogastado葡语不规则

5.1 双分词现象（particípio duplo）

部分动词有两个分词：规则形配 ter（构成 composto），不规则形作形容词（常配 ser/estar）：

Ele tem aceitado o convite. × um homem aceito na sociedade
他一直接受这个邀请（规则形 aceitado 配 ter）。× 一个被社会接纳的人（不规则形 aceito 作形容词）。同类：tem pagado/pago、tem entregado/entregue、tem gastado/gasto。

6. 其他体貌结构：acabar de · continuar · 等

结构含义例句（葡）西语对照
acabar de + 不定式刚刚（做完）Eu acabei de comer. / Acabou de sair o resultado.acabo de comer（一致，巴西人用它替代 he comido）
continuar + gerúndio继续做Ele continua trabalhando.sigue trabajando（葡语用 gerúndio 更地道）
começar a + 不定式开始做Começou a chover.empezó a llover（一致）
andar + gerúndio（口语）近来一直Ela anda estudando muito.anda estudiando（两语口语一致）
voltar a + 不定式重新/再次做Ele voltou a trabalhar.volvió a trabajar（一致）
