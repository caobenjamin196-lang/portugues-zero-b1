西语者须知：本周读真正的巴西文学。好消息：西语和葡语的叙事传统共享同一套时态系统，你读西语小说的经验 90% 直接可用。要补的只有三处：mais-que-perfeito 简单式（西语口语已少用，葡语文学里活着）、对话标点的差异（葡语用 travessão 不用西语式引号）、以及自由间接引语在葡语第三人称叙事里的高频。读完本周的短篇小说，你就摸到了 B1 阅读的天花板。

1. 文学时态地图：小说里每个时态干什么活

时态文学功能例句
pretérito perfeito推进情节：动作、事件Ela abriu a porta e saiu.
pretérito imperfeito布景：环境、习惯、心理Chovia. A vila dormia. Ele pensava nela.
mais-que-perfeito 简单式（falara）闪回：先于主线发生的事Reconheceu a casa onde nascera.
mais-que-perfeito 复合式（tinha falado）同上，口语/现代文常用Ela tinha prometido voltar.
历史现在时制造临场感（高潮处）De repente, ele abre os olhos.
futuro do pretérito「彼时未知」的命运预告Não sabia que nunca mais a veria.
虚拟式过去未完成假设、愿望、梦境Se pudesse, voltaria no tempo.

2. mais-que-perfeito 简单式：文学的「闪回键」

构成：不定式词干 + -ra / -ras / -ra / -ramos / -ram。西语者注意——词形像西语过去未完成虚拟式（hubiera 的姊妹），但葡语这里是陈述式过去完成：

动词简单式 mais-que-perfeito复合式（= 同义）西语对照
falarfalara / falaras / falara / faláramos / falaramtinha faladohabía hablado
partirpartira / partiras / partira / partíramos / partiramtinha partidohabía partido
fazerfizera / fizeras / fizera / fizéramos / fizeramtinha feitohabía hecho
vervira / viras / vira / víramos / viramtinha vistohabía visto
读音陷阱：falara（他说过）重音在 -la-，而 falará（他将说）重音在 -rá——一个重音符号，隔着过去与将来。文学里靠重音定生死。
使用语域：简单式（falara）= 文学、正式文书；复合式（tinha falado）= 日常口语、现代小说也大量用。B1 只要求看懂简单式，写作时用 tinha + 分词永远不错。

3. 叙述体三层：谁在说话？

层次标志例句
叙述者语言第三人称 + 过去时O velho caminhava devagar pela praia.
直接引语travessão（—）或 aspas— Eu vi o mar engolir o barco — disse ele.
自由间接引语无引号，人物心声混进叙述Ele olhou o horizonte. Será que ela voltaria? O mar não respondia.

对话描写规则（与西语的关键差异）：

— Onde você esteve? — perguntou ela, sem olhar para ele.
— Por aí — respondeu. Fitou o chão.
— Mentira — ela soluçou. — Eu vi você no cais.

葡语对话用 travessão（—）开头，说话人换行；插入语（perguntou ela）后用逗号接回。西语用 « » 或同样破折号——但葡语不用西语式 ¡ ! 前导符号，也没有 opening/closing 引号对。对话标签常用 disse/perguntou/respondeu/murmurou/sussurrou/gritou + 主语后置。

4. 自由间接引语：文学鉴赏的最后一公里

叙述者的语法 + 人物的语气 = 自由间接引语。辨认它，是 B1 阅读理解的常考题型：

写法句子谁在说话
直接引语Ele disse: — Eu nunca mais volto.人物（有标记）
间接引语Ele disse que nunca mais voltaria.叙述者转述
自由间接引语Ele fechou a porta. Nunca mais voltaria. A casa ficou para trás.叙述外衣 + 人物内心
辨认三信号：① 没有 disse/pensou 标记却有人称观点；② 出现感叹词、口语词（aí, então, é que）；③ 时态跟着叙事过去时走，但视角是人物的。西语（estilo indirecto libre）一模一样，凭西语阅读经验即可迁移。

句型意思例句
