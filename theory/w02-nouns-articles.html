📦 名词 / 冠词 / 形容词：阴阳性转移规则

-ción→-ção · -dad→-dade · -ón→-ão · 形容词位置 · 复数规则

← 仪表盘
好消息：阴阳性概念、形容词性数一致、定冠词系统——这些你已经会了。本周只需掌握词尾转换规则和少数阴阳性翻转的坑。

1. 冠词系统

阳性单数阴性单数阳性复数阴性复数
定冠词o livroa casaos livrosas casas
不定冠词um livrouma casauns livrosumas casas
西语对照el / unla / unalos / unoslas / unas

注意发音：o 读 /u/，um 读鼻化 /ũ/。

2. 西语 → 葡语词尾转换五大规则

西语词尾葡语词尾例词阴阳性
-ción-çãonación → nação；información → informação阴性（同西语）
-dad-dadeciudad → cidade；libertad → liberdade阴性（同西语）
-ón-ãocorazón → coração；avión → avião阳性（同西语）
-aje-agemel viaje → a viagem；el paisaje → a paisagem⚠️ 西语阳性 → 葡语阴性！
-miento/-amento-mentoapartamiento → apartamento阳性（同西语）
最大陷阱：el viaje（阳） → a viagem（阴）。所有 -agem 词都是阴性，与西语 -aje 阳性相反。类似的还有 el mensaje → a mensagem、el equipaje → a bagagem。

3. 阴阳性：与西语一致 + 例外清单

约 95% 的名词阴阳性与西语一致。必须死记的共同例外：

  • o dia（= el día）—— 两语都阳性
  • o problema, o tema, o sistema, o programa —— 希腊语源 -ma 词阳性（= 西语）
  • a mão（= la mano）—— 两语都不规则阴性
  • a flor, a cor, a dor —— -r 结尾抽象名词阴性（= 西语）

真正不同的（葡 ≠ 西）：a viagem/a bagagem（阴） vs el viaje/el equipaje（阳）。

4. 复数规则

结尾规则例词
-o / -a / -e加 -slivro→livros, casa→casas, flor→flores
-l去 -l 加 -isazul→azuis, hotel→hotéis, papel→papéis
-m-m → -nshomem→homens, viagem→viagens
-r / -z加 -esflor→flores, feliz→felizes
-s（重读末音节）加 -espaís→países, português→portugueses
-ão多数 → -ões；少数 → -ães / -ãoslição→lições, pão→pães, mão→mãos

标音注意：复数变化后要保持原重音位置，常需补重音符号：hotel→hotéis, papel→papéis。

5. 形容词：位置与性数一致

5.1 默认后置（与西语相同）

um carro vermelho ・ uma flor bonita ・ os hotéis caros
一辆红车 ・ 一朵美丽的花 ・ 昂贵的酒店们 —— 形容词在名词后，保持性数一致

5.2 性数变化类型

  • 四形式：bonito / bonita / bonitos / bonitas
  • 两性同形（只变复数）：grande→grandes, feliz→felizes, azul→azuis（feliz/azul 与名词一起变复数！）

5.3 位置改变意义（与西语类似）

um grande homem（一个伟大的人）vs um homem grande（一个高大的男人）
grande 前置=伟大，后置=高大 —— 与西语 un gran hombre / un hombre grande 完全平行
