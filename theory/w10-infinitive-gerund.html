第 10 周 · Phase 3

🧩 不定式与动名词：infinitivo pessoal + gerúndio

É importante estudarmos juntos · antes de saírem · Ao chegar, liguei · 葡语独有的人称化不定式

← 仪表盘
西语者须知：人称化不定式（infinitivo pessoal）是葡语独有的语法珍品——不定式居然可以带人称词尾：É importante estudarmos juntos.（我们一起学习很重要）。西语遇到这种情况必须动用虚拟式从句：Es importante que estudiemos juntos. 葡语一个动词形式搞定，更简洁。好消息：人称化不定式永远规则——连 ser、ir、fazer 都不例外。动名词（gerúndio）则是你的老朋友：estou estudando = estoy estudiando，本周只学它和不定式的分工。

1. 人称化不定式：构成（比 W9 还简单）

不定式原形 + 人称词尾：∅ / -es / ∅ / -mos / -em
falar → eu falar · tu falares · ele falar · nós falarmos · eles falarem
词尾与 W9 虚拟将来时一模一样，但词干永远用不定式——没有不规则动词！
动词eu/elenóseles对比 W9 虚拟将来时
falar（规则）falarfalarmosfalarem两种时态同形
sersersermosserem虚拟将来时是 for/formos/forem！
tertertermosterem虚拟将来时是 tiver/tivermos/tiverem！
fazerfazerfazermosfazerem虚拟将来时是 fizer/fizermos/fizerem！
iririrmosirem虚拟将来时是 for/formos/forem！
本周唯一的记忆负担：不规则动词的人称化不定式和虚拟将来时（W9）词干不同：para nós fazermos（不定式）vs se nós fizermos（虚拟将来）。分辨靠触发词：para/sem/antes de/ao 后面 → 不定式；se/quando/assim que 后面 → 虚拟将来时。

2. 人称化不定式：四大用法

2.1 主从句主语不同 → 省去虚拟式从句

葡语（简洁）西语（必须展开从句）中文
É importante estudarmos juntos.Es importante que estudiemos juntos.我们一起学习很重要。
É melhor vocês esperarem aqui.Es mejor que ustedes esperen aquí.你们最好在这儿等。
Lamento eles não poderem vir.Lamento que no puedan venir.很遗憾他们不能来。

2.2 介词后 + 明确主语

Antes de saírem, fechem a porta. / Sem falares comigo, não decido. / Trouxe bolo para vocês provarem.
你们离开前，请关门。/ 你不跟我谈，我就不做决定。/ 我带了蛋糕给你们尝。
= 西语 antes de que salgan / sin que hables / para que prueben——西语必须 que + 虚拟式，葡语直接 介词 + 人称不定式。

2.3 ao + 不定式 = 时间从句「一……就」

Ao chegar em casa, liguei para ela. / Ao abrir a porta, viu o presente. / Ao chegarmos ao hotel, começou a chover.
我一到家就给她打了电话。/ 她一开门就看到了礼物。/ 我们一到酒店就下起雨来。
= 西语 Al llegar… / Al abrir…——两语结构一致，葡语还能加人称（ao chegarmos）。

2.4 主语相同时用不带人称的普通不定式

É importante estudar todos os dias. / Quero viajar no verão.
每天学习很重要（泛指）。/ 我想夏天去旅行（同一主语）。
⚠️ 主语相同或泛指时，不要加人称词尾：*Quero viajaro ❌（eu 形式 = 原形，碰巧不露馅）；但 *É importante estudarmos 只有主语是「我们」时才对。

3. 动名词 gerúndio：复习 + 与不定式分工

场景用哪个例句西语对照
进行时（estar +）动名词Estou estudando.estoy estudiando（一致）
方式/时间状语动名词Ela aprende ouvindo música. / Saindo cedo, você evita o trânsito.escuchando / saliendo（一致）
介词后不定式antes de sair / sem falar / para estudarantes de salir / sin hablar（一致）
ao + 动词「一……就」不定式Ao chegar, liguei.Al llegar…（一致）
作主语/宾语不定式Fumar faz mal. / Gosto de ler.Fumar hace daño（一致）
acabar de / deixar de / voltar a不定式Acabo de chegar. / Deixou de fumar. / Voltou a chover.acaba de llegar / dejó de fumar / volvió a llover（一致）
巴西 vs 葡萄牙进行时：巴西说 estou fazendo（estar + 动名词，同西语）；葡萄牙本土说 estou a fazer（estar a + 不定式）。学习巴西葡语，一律用 estar + 动名词；看到葡国的 a fazer 知道是进行时即可。
西语者的英语化陷阱：英语 "before leaving" 用动名词，西葡语介词后都用不定式：antes de sair = antes de salir（*antes de saindo ❌）。这点两语一致，别被英语带偏。

4. 速查：看到触发词选形式

触发词后接例句
para / sem / antes de / depois de / apesar de不定式（±人称）Apesar de estarem cansados, continuaram.
ao不定式Ao abrir os olhos, sorriu.
é importante / melhor / difícil + 明确主语人称不定式É difícil eles aceitarem isso.
se / quando / assim que（未来）虚拟将来时（W9）Se fizerem isso, avise.
estar / andar / continuar动名词Continua chovendo.
